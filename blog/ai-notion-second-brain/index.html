How to Build an
AI Second Brain in Notion

8 min read Workflow Setup May 2025 Works on free plan

A "second brain" is a system that stores, connects, and surfaces information so you don't have to keep it in your head. Add AI to that — a prompt library, AI-enhanced note capture, and automated workflows — and you get a workspace that actively helps you think, not just store things.

Free vs paid Notion

Everything in the database structure below works on the Notion free plan. Notion AI (the built-in AI assistant) requires a paid plan, but you can replicate its functionality by copying content into Claude or ChatGPT. The free plan is genuinely enough to get started.

The Eight Databases

The system is built on eight interconnected databases. Each one has a purpose — nothing is redundant. They're linked through Notion's relation and rollup properties, so information flows between them without manual copying.

📝
Notes
Raw captures — ideas, observations, meeting notes, articles saved for later. No perfectionism here. Quantity over quality. AI helps clean and categorise later.
🗂️
Projects
Active work. Each project links to its related notes, tasks, and resources. Status, deadline, and linked deliverables in one view. The command centre.
⌬
Prompt Library
The most-used AI prompts saved and categorised. Tagged by use case (email, research, writing, coding). Each has a title, the prompt body, and notes on when it works best.
🔧
Tools
Every AI tool I've tested — rating, cost, use cases, verdict. Linked to the notes taken while testing them. Never forget what you've already evaluated.
👥
People & Contacts
Not a CRM — a context database. Key things to remember about collaborators, clients, and contacts. Meeting notes linked here automatically via the Notes database.
✅
Tasks
Action items linked to the projects that contain them. Due dates, priorities, and a "Today" filtered view. Separate from Projects — tasks are granular, projects are strategic.
📚
Resources
Books, articles, videos, and podcasts worth revisiting. Tag by topic. AI-generated summaries saved alongside each resource so you can retrieve insights without re-reading everything.
🔄
Weekly Review
A database of weekly review entries — wins, blockers, focus for next week. Reviewable over time. Pair with an AI prompt to generate the entry from your weekly activity.

How to Build It

Follow these steps in order. Don't try to build everything at once — a system you actually use is better than a perfect system you never open.

1
Create the Notes database first
In a new Notion page, create a full-page database called "Notes." Add these properties: Name (title), Status (select: Inbox / Processing / Reference / Archive), Tags (multi-select), Date (created time), Source (text), and AI Summary (text). This is where everything enters the system. Start capturing immediately, even before the rest is built.
2
Add the Projects database
Create a Projects database. Add: Status (select: Active / On hold / Complete), Due date, Priority, and a Relation property that links to Notes. Now every note can be linked to the project it belongs to. Add a filtered view called "Active" showing only in-progress projects — this becomes your daily dashboard.
3
Build the Prompt Library
Create a database called "Prompt Library." Properties: Name, Category (select: Writing, Research, Email, Code, Strategy, Other), Model (works best with which AI), Prompt Body (text), and Notes (text for caveats). Populate it with the 50 prompts from the free kit as your starting set, then add your own as you discover what works.
4
Create the Tasks database and link to Projects
Tasks database with: Name, Done (checkbox), Due date, Priority, and a Relation to Projects. Add a "Today" filtered view (Due = today, Done = unchecked). This single view replaces a to-do app for most people. When you open Notion each morning, this is what you look at first.
5
Set up the Weekly Review database
Create a Weekly Review database with: Week ending date, Wins (text), Blockers (text), Carry-overs (relation to Tasks), Focus next week (text). Then create a prompt in your Prompt Library: "Based on the following week's notes and completed tasks, draft a concise weekly review covering: three wins, two blockers, and three priorities for next week. Keep it under 200 words." Paste your weekly output into Claude to generate the review draft.
6
Build a Home dashboard page
Create a page called "Home" (set it as your Notion start page). Use linked database views to show: Today's Tasks, Active Projects, Recently added Notes (Inbox filter), and a link to the Prompt Library. This becomes your daily entry point. Everything visible in one place, no clicking around to find what you need.
7
Add AI to your capture workflow
The most powerful habit: when you add a note to the Inbox, paste it into Claude with this prompt: "Summarise this note in two sentences. Suggest 2–3 tags from these categories: [your tag list]. Identify any action items." Paste Claude's response back into the AI Summary field. You now have searchable, structured notes instead of a pile of raw text. Takes 60 seconds per note.
8
Skip the Tools and Resources databases for now
Build these once the core six databases are working and you're using the system daily. Adding too much structure too early is how second brain systems get abandoned. The minimum viable system is Notes + Projects + Tasks + Weekly Review. The rest is optional enhancement.
The one habit that makes it stick

Spend 10 minutes every morning opening the Home dashboard. Check Today's Tasks, glance at Active Projects, process anything in the Notes Inbox. If you skip the daily habit, the system dies. The tech is secondary to the routine.
